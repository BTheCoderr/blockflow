Support

If a puzzle, timer, World Run, or Boss phase behaves unexpectedly, your current game state is saved locally whenever possible.

Report a problem

Open a GitHub issue with the level name, mode, what you expected, and what happened.

Open a support issue

Playtest diagnostics

On the Block Flow home screen, tap Copy playtest report. It copies anonymous local aggregates such as starts, restarts, undos, solve times, and moves. Paste that report into your support issue if it helps reproduce the problem.

Resetting a stuck session

Changing worlds ends the active saved session for the previous world. Restart Level also creates a fresh board while keeping permanent level progress.
